Chapter 3 Technical Architecture Breakdown

1. Tier 1: Client Systems (Presentation)

Encompasses Customer mobile and workstation devices interacting through responsive web browsers with the Customer Web Portal, and dedicated Administrator workstations running the salon management control dashboard.

2. Tier 2: Public Internet & Transport Gateway

Guarantees end-to-end transport layer security through HTTPS/TLS 1.3 encryption (TCP Port 443), Secure WebSockets (WSS) for zero-latency bidirectional event broadcasting, and global edge Anycast routing.

3. Tier 3: Web Application Server (Vercel)

Full-stack Next.js serverless cloud infrastructure hosting the React UI presentation layer, secure API routes (/api/*), all core Salon MIS business logic modules, and the AI-Integrated Nail Customization & Recommendation Engine.

4. Tier 4: Database & Storage (Supabase)

Cloud PostgreSQL 15 database persisting relational tables for appointments, customer records, inventory, and billing; S3-compatible cloud object storage for nail portfolios; and Supabase Realtime CDC engine.

5. Federated Authentication (Google Auth)

Provides single sign-on (SSO) via OAuth 2.0 / OpenID Connect brokered through Supabase Auth, exchanging cryptographically signed JWT tokens for secure session validation without plaintext credential risks.

6. Transactional Email Service (Resend API)

High-deliverability cloud transactional email infrastructure triggered via authenticated HTTPS REST POST endpoints to deliver booking confirmations, status updates, and administrative OTP verification codes.
